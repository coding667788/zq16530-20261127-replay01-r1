我们在替换一套离线票据台账。请实现 revokerace，按带业务时间和单调入库编号的合成事件，重放令牌家族。每次轮换必须消耗一个当前令牌并产生一个新令牌；同请求重复投递可返回原结果。两个不同请求竞争同一父令牌时只能有一个成功，后到的竞争记为重用并隔离整族。隔离从发现时起阻止后续使用，同时在最终审计中标出发现前已经放行的衍生会话。受控签发和注销可同秒生效，先按明确的可信序列排，缺序则保留不确定性而不是随输入次序取胜。
做 apply、asof、explain 三个入口；支持崩溃后重放同一批指令且事件、回执、隔离记录同时生效，人工补登不能改写此前的历史视图。输出能复核的首个重用见证及其影响清单。必须在可控故障点杀掉一个子进程，另起进程验证事务一致；另给同样输入乱序、分批、并发两客户端结果的回归。只允许合成令牌 ID 和本地数据，不连接身份服务。
从空仓库开始，在 Windows 普通 CPU 上用 Python 3.12 标准库交付。命令输出 UTF-8 JSON，附 README、合成夹具和可直接运行的 unittest。
